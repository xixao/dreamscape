# Reference briefs — parked for later

Status: deferred by the designer. Do not implement until requested.

## Concept
Search Mobbin, select screenshots, and import them into an automatically named reference Section such as “References · Desktop loan dashboard.” Arrange screenshots at consistent display heights with original proportions, wrap large collections into rows, and retain product names/source links. Reference objects never appear in prototypes or generated code.

## Relationship to Pages
A file-level References page provides a stable home. Each named Section is a brief containing screenshots, marked regions, and designer notes. Designers may show a linked brief beside their working frames on any design page; edits update the original, and hiding that view does not delete the brief. Chat can attach a brief from any page even when it is not visible. Use existing canvas/Sections/lasso/Chat, plus a search/import modal rather than a separate research editor.

## AI workflow
Find → circle → explain → apply → compare. Lasso screenshot regions and annotate what matters (“filter layout,” “navigation structure,” “table density”). Keep the target and references distinct in Chat: “Target · Loan pipeline frame” and “References · 4 screens.” Summarize the intended interpretation before generating. Apply only requested ideas using the file theme and available coded components; identify missing library capabilities explicitly.
